# Drinks Market — Telegram Mini App + Backend + Admin

Полный проект магазина газированных безалкогольных напитков:
- Telegram Mini App: каталог, поиск, корзина, checkout, история заказов.
- Node.js/Express API.
- SQLite: постоянное хранение каталога, заказов и остатков.
- Уведомления о новых заказах в Telegram администратору.
- Админ-панель `/admin`: добавление/редактирование/скрытие товаров, изменение цен и остатков, просмотр заказов и смена статусов.

## 1. Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm install
cp .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN` — токен бота от @BotFather.
- `ADMIN_CHAT_ID` — ваш Telegram user ID (например, его показывает @userinfobot).
- `ADMIN_TOKEN` — длинный случайный пароль админки.
- `REQUIRE_TELEGRAM_AUTH=false` — оставьте false для локальной проверки в обычном браузере. На публичном запуске установите true.

Запуск:

```bash
npm start
```

Откройте `http://localhost:3000`. Админ-панель: `http://localhost:3000/admin`.

## 2. Уведомления о заказах

1. Создайте бота через @BotFather и скопируйте токен в `BOT_TOKEN`.
2. Откройте чат с ботом и нажмите Start.
3. Узнайте свой Telegram user ID через @userinfobot и укажите его в `ADMIN_CHAT_ID`.
4. После оформления заказа сервер отправит сообщение боту администратору.

## 3. Подключение Telegram Mini App

1. Разместите проект на Node.js-хостинге с HTTPS и постоянным диском.
2. Установите переменные окружения из `.env.example` на хостинге.
3. Убедитесь, что `https://ВАШ-ДОМЕН/api/health` отвечает `{"ok":true}`.
4. В @BotFather настройте Mini App / Web App и укажите `https://ВАШ-ДОМЕН`.
5. Для публичной работы установите `REQUIRE_TELEGRAM_AUTH=true`.
6. Запускайте Mini App из Telegram. Сервер проверяет подпись `initData` и не принимает его неподписанным.

## 4. Админ-панель

Перейдите на `https://ВАШ-ДОМЕН/admin` и введите `ADMIN_TOKEN`.
- Товары: добавление, редактирование названия/описания/категории/цены/объёма/изображения/остатка; скрытие позиции.
- Заказы: список заказов, контактные данные, состав и сумма; смена статуса.
- Новые заказы отправляются в Telegram на `ADMIN_CHAT_ID`.

## 5. Важные эксплуатационные моменты

- Используйте только HTTPS в публичной среде.
- `ADMIN_TOKEN` должен быть длинным и секретным. Не отправляйте его покупателям и не храните в репозитории.
- Включайте `REQUIRE_TELEGRAM_AUTH=true` на публичном домене.
- Хостинг должен поддерживать постоянный диск для `shop.sqlite` и резервное копирование. Если файловая система эфемерная, SQLite-файл может исчезнуть после перезапуска или нового деплоя.
- Цены и остатки берутся с сервера при создании заказа, а не доверяются данным браузера.
- Демо-каталог содержит только газированные безалкогольные напитки. Оплата и интеграция с курьерской службой не подключены.
- Для коммерческого запуска добавьте политику обработки персональных данных, ограничение частоты запросов, HTTPS, бэкапы и настройте сроки хранения контактных данных.
